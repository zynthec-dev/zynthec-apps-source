Melde dich mit deinem GitHub-Zugangsschlüssel an, um Apps hinzuzufügen und deine Source zu verwalten.

Ersten Zugang einrichten
  1. Erstelle in GitHub einen Fine-grained personal access token ↗.
  2. Wähle als Resource owner zynthec-dev und unter „Only select repositories“ ausschließlich zynthec-ios-sideload-source.
  3. Erlaube Contents: Read and write und Actions: Read and write. Metadata erhält automatisch Leserechte. Wähle eine passende Ablaufzeit.
  4. Kopiere den Schlüssel in das Feld oben. Bewahre ihn in deinem Passwortmanager auf.

Der Schlüssel wird nur während dieser geöffneten Sitzung verwendet und an GitHub weitergereicht. Er wird nicht im Browser gespeichert. Zugriff erhält nur zynthec-dev.
